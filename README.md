### Featured projects

**[Used Car Dynamic Pricing Engine](https://github.com/AkashB-17/Used_Cars_Price_Prediction)**
End-to-end ML pricing engine built for a CARS24 internship application. Random Forest model
trained on ~6K listings (R² = 0.89, MAE ≈ ₹1.49L), served through a FastAPI backend with
`/predict` and `/explain` endpoints, and a styled Gradio UI. Deployed live on Render.
`Python` `scikit-learn` `FastAPI` `Gradio` `Render`

**[PII Redactor Tool](https://github.com/AkashB-17/PII_Redactor_tool)**
A hybrid regex + spaCy NER pipeline that detects and redacts personally identifiable
information from real financial/legal documents (built against a Red Herring Prospectus).
Handles both DOCX (paragraphs + tables) and PDFs, with Faker-based consistent
pseudonymization and a full precision/recall evaluation framework. Deployed as a Streamlit
app on Render.
`Python` `spaCy` `PyMuPDF` `Streamlit` `Render`

**[CareerOS](https://github.com/AkashB-17/CareerOS)**
A personal AI networking agent built to land a remote AI/DS internship — automates research
and outreach while staying strictly human-in-the-loop. Built on LangGraph (chosen over
CrewAI/OpenAI Agents SDK) with a Streamlit UI and SQLite/SQLModel for persistence.
`Python` `LangGraph` `Streamlit` `SQLModel` `OpenAI API`

**[NHAI Hackathon — Face Auth Pipeline](https://github.com/AkashB-17/NHAI_Hack)**
An ONNX-quantized face authentication pipeline built for a hackathon, optimized for fast,
lightweight on-device inference.
`Python` `ONNX` `Computer Vision`

**[Adobe Emerge — NL-to-SQL](https://github.com/AkashB-17/Adobe_Emerge)**
A natural-language-to-SQL interface that turns plain English questions into executable
queries.
`Python` `NLP` `SQL`

**[Exam GPT](https://github.com/AkashB-17/Exam_GPT)**
An LLM-powered exam preparation assistant.
`Python` `LLM`

> 📌 A couple of older/smaller repos (churn prediction, house price prediction, etc.) still
